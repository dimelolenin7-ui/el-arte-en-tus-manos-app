# 🧶 El Arte en Tus Manos

Academia interactiva y biblioteca de videos de amigurumis y manualidades.

🔗 **App en línea:** https://dimelolenin7-ui.github.io/el-arte-en-tus-manos-app/

---

## ✨ Qué incluye

- Cursos y retos paso a paso de amigurumis y manualidades.
- Videos organizados por categorías, con favoritos y contador de vueltas.
- Planes **Gratis**, **Pro** y **Premium** con distintos niveles de acceso.
- Calculadora de costos y precios de venta (Premium).
- Buzón para sugerir nuevos cursos y videos (Premium).
- Instalable en el celular como aplicación (PWA).
- Inicio de sesión con correo y contraseña, o con Google.

## 🛠️ Tecnología

- HTML, CSS y JavaScript
- Firebase Authentication y Firestore
- Alojada en GitHub Pages

## 📲 Instalación en el celular

Abre la app en tu navegador y toca **Descargar la App**. También puedes usar el menú ⋮ del navegador y elegir **Instalar aplicación**.
